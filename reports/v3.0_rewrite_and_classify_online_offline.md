# v3.0 — REWRITE → REWRITE_AND_CLASSIFY (phân loại online/offline) (data + model)

- **Ngày:** 2026-06-09
- **Model:** vi-rewriter LoRA (cần re-train) | **Bench:** sẽ regen (thêm pattern online)
- **Động cơ:** Sản phẩm yêu cầu module vừa viết lại câu vừa PHÂN LOẠI domain
  `{online, offline}`. Repo cũ chỉ làm rewrite-only (`{"rewrite_message"}`, tag
  `<REWRITE>`) — thiếu hẳn chiều domain. Toàn bộ data cũ lại đều là offline (điều
  khiển/nav/media) → nếu chỉ gắn nhãn, classifier sẽ suy biến (luôn đoán offline).

## Đã làm (code, đã verify local)
- **Schema task mới:** `prompts.py` — `SYSTEM_PROMPT_FOR_TRAINING` + `BASELINE_SYSTEM_PROMPT`
  thêm định nghĩa online/offline; `REWRITE_TAG` = `<REWRITE_AND_CLASSIFY>`; output JSON =
  `{"rewrite_message": "...", "domain": "online|offline"}`.
- **Trường domain vào output** ở mọi hàm build sample (param `online_offline="offline"`):
  `generate_multi_turn.make_sample`, `generate_dataset.make_sample`, `patch_b2b3.sample`,
  `generate_vllm.to_lf`, `build_benchmark.to_lf_record` (+`BenchSample`), `convert_to_lf`.
  Giữ `meta.domain` (9 nhãn chức năng) cho stratify, thêm `meta.online_offline`.
- **Thay mọi literal `<REWRITE>`** → `REWRITE_TAG`/tag mới (eval_bench, generate_vllm,
  patch_b2b3, build_benchmark, append_confirmation_bench, judge_api, patch_short_contextual,
  analyze_train_distribution, paraphrase_with_llm).
- **Nguồn ONLINE mới:** `src/data/generate_online.py` — chit-chat, hỏi đáp kiến thức chung,
  cách dùng/khắc phục lỗi xe; multi-turn + giải đại từ/ellipsis. Sinh **1514 mẫu** (114 gold
  riêng, cap 24/gold, 0 rò đại từ trong gold). Ranh giới: "kể truyện cười" & "tìm địa điểm"
  vẫn là offline (loại khỏi online); phần xe = HỎI-ĐÁP ("...là sao?/thế nào?") tương phản
  câu LỆNH điều khiển (offline).
- **Bench online:** thêm pattern `online_general_qa`, `online_vehicle_howto` vào
  `build_benchmark` (gán `online_offline="online"`).
- **Eval domain-accuracy:** `eval_bench.py` — `extract_pred_domain`, `deterministic_metrics`
  (domain_valid/domain_correct), aggregate `domain_accuracy`/`domain_validity`,
  `_domain_breakdown` (accuracy + confusion theo lớp gold), in trong report. Chấm bằng
  so khớp chuỗi (không tốn token judge).
- **Pipeline:** `build_train_mix` report thêm `by_online_offline`; `split_data`
  `DEFAULT_STRATIFY_BY` thêm `meta.online_offline`; recipe `data/recipes/v5.yaml` thêm nguồn
  `online_synth` + stratify online.
- **Migrate rẻ:** `src/data/migrate_to_classify.py` — chuyển data cũ (base/patches/bench)
  sang format mới + `domain:offline` mà KHÔNG cần regen LLM (idempotent). Tránh sinh lại 20k.
- **Đồng bộ Kaggle:** `kaggle_gen_data.ipynb` cell `prompts.py` + `generate_vllm.py` đã
  khớp byte với file src.

## Trình tự chạy (Kaggle/local)
1. Migrate data cũ (offline): `python -m src.data.migrate_to_classify --input data/train/dialogues_train_api.jsonl --inplace --system` (lặp cho `data/patches/*.jsonl`, `data/bench/*.jsonl`).
2. Sinh online: `python -m src.data.generate_online --target 0 --output data/raw/dialogues_online.jsonl` (đã có sẵn).
3. Ráp: `python -m src.data.build_train_mix --recipe data/recipes/v5.yaml` → kiểm `by_online_offline` trong `dataset_report.md` (KHÔNG ~0% online).
4. Regen bench (có online): chạy `build_benchmark` với pattern `online_general_qa`, `online_vehicle_howto`.
5. Train lại LoRA (`kaggle_run.ipynb`) → serve → eval (`eval_bench.py`) đọc `Domain Accuracy` + slice online ≠ 0.

## Kết luận
Hạ tầng task REWRITE_AND_CLASSIFY đã sẵn sàng và verify local đầy đủ. Bước còn lại là
regen/migrate data + retrain trên Kaggle; theo dõi `domain_accuracy` (đặc biệt slice online)
và đảm bảo `command_acc` rewrite không tụt. Online hiện ~1.5k (deterministic) — nếu slice
online yếu, mở rộng pool `generate_online.py`/nâng `MAX_PER_GOLD` hoặc bổ sung bằng teacher.
